# Coral Resort Management コーポレートサイト（デザイン確認用）

## 中身
```
index.html          トップページ＋代表挨拶ページ（1ファイル完結）
assets/img/*.jpg    掲載画像
```

## アップロード手順
1. FTP / ファイルマネージャーでサーバーの公開ディレクトリ（`public_html` や `www`）を開く
2. **index.html と assets フォルダをフォルダ構成のまま**アップロード
3. `https://ドメイン/` を開いて表示を確認

サブディレクトリで確認する場合は `public_html/preview/` などに一式を入れ、
`https://ドメイン/preview/` でアクセスしてください。

## 公開前に必ず対応すること
- `index.html` 冒頭の `<meta name="robots" content="noindex,nofollow">` を削除（検索避けの指定）
- ページ最上部の黄色い注意書き（`<div class="note">…</div>`）を削除
- ヒーロー背景のYouTube映像（他者の空撮映像を仮に埋め込み）を自社撮影素材に差し替え
- 「※要確認」表記、仮のニュース3件、電話番号の扱いを実データに更新
- 会社概要の内容、代表挨拶の文面を最終確認

## 補足
- 外部読み込みはGoogle Fonts（書体）とYouTube（ヒーロー映像）のみです
- お問い合わせボタン・各リンクは未接続（`#`）です。フォーム設置時にリンク先を設定してください
- 画像を差し替える場合は `assets/img/` 内の同名ファイルを上書きすれば反映されます
